# Iridium 0.1.0

## Summary

Iridium 0.1.0 is an experimental Windows-game runtime for iPhone and iPad. Add your own game folder, choose its executable, and launch it from the library. Game compatibility varies by device and title.

## Changes

### Added

- Game library with editable titles and artwork, Favorites, and search.
- Game Options for controls, files and saves, and advanced launch settings.
- Wine, FEX, and graphics integration based on Madeira's runtime.
- JIT setup, launch progress, session logs, and performance controls.
- Touch, controller, keyboard, and mouse input paths, with mouse and scroll sensitivity settings.

These features are included in the app. Their presence does not establish compatibility with every game or input device.

## Installation and requirements

Requires iOS or iPadOS 27.0 or later and user-supplied Windows game files.

The IPA is unsigned. Use a suitable sideloading tool to sign both the app and its helper extensions before installation. Signing alone does not enable JIT. Configure JIT through Launch Support before starting a game; external JIT requires a compatible installed helper and its setup.

See the [installation and build instructions](../actions-ipa.md) and [product guide](../../iridium/docs/product-experience.md).

## Migration and saves

This is the first public release; no prior public-release migration is defined.

Before replacing a development build, back up game saves and imported game folders. Preserve the existing app container when your signing tool supports an update. Do not uninstall the old app as an upgrade step: removing it can delete its local data. Compatibility with every earlier development build has not been verified. Removing a library entry is separate from deleting game files or saves.

## Known limitations

- Experimental release: successful launch does not establish full game compatibility.
- Earlier Skyrim tests reported missing speech audio and problems with mouse attack input. Resolution is not verified in this candidate.
- Video playback is not verified across games and media formats.
- JIT availability depends on the device, OS, signing method, and helper setup.
- Apple compiler-runtime notice uncertainty remains a documented licensing risk. Public unsigned-IPA contractual authorization is a separate acknowledged risk outside the open-source compliance audit.

After downloading both archives and `SHA256SUMS` into one folder, run:

```sh
shasum -a 256 -c SHA256SUMS
```

Both entries must report `OK`. The source package includes the application source, required dependency sources and modifications, license notices, and instructions to rebuild and replace the runtime libraries.
